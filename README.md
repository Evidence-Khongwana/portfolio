# Informatics Student Portfolio

A responsive, single-page portfolio designed for an informatics student and ready for GitHub Pages.

## Personalise it

Open `dist/index.html` and replace:

- `Evidence Khongwana` is the portfolio name
- `your.email@example.com` with your email
- The GitHub links point to `Evidence-Khongwana`; replace the LinkedIn placeholder with your profile
- The sample education, project, and skill details with your own work

## Publish on GitHub Pages

Copy the contents of `dist/` to the repository root (or configure GitHub Pages to deploy from it), then enable Pages in the repository settings.

No build tools or dependencies are required.
