# Evidence Khongwana — Portfolio

A responsive professional portfolio presenting Evidence's focus across informatics, business analysis, data, and digital systems.

## Content notes

The project examples are presented as academic or student concepts so the portfolio does not imply unverified client work. Before applying for roles, update `dist/index.html` with:

- Evidence's university or college and expected graduation date
- Confirmed project details and links to separate repositories
- A professional email and LinkedIn URL, if desired
- Any verified work experience, certifications, or achievements

## Local preview

Open `dist/index.html` directly in a browser. No build tools or dependencies are required.

## GitHub Pages

The included workflow deploys `dist/` whenever changes are pushed to `main`. In the repository settings, set **Pages → Source** to **GitHub Actions**.
